## What sets this modpack:
* **Vulkan Graphics API**
* Includes all the needed optimization mods: **Sodium, Lithium, FerriteCore, ModernFix, EntityCulling, ImmediatelyFast, AsyncParticles, C2ME, Ixeris, Lomka, LCull, Async Logger, AsyncParticles, quick-pack** for buttery-smooth performance
* Packed with a ton of SkyBlock-specific QOL mods: **SkyHanni, Skyblocker, SkyOcean, Skysoft, SBO, Odin, SkyBlock Profile Viewer**
* Visual enhancements like **Catharsis, Capes, Continuity, Polytone, ThirdPersonNametags, Iconographic, Zoomify and Skysoft's Voxy alternative** (Keep Terrain Loaded)
* Pre-configured mods and resource packs for Hypixel Skyblock with the only necessary features
* Fully open source with **MIT License**
